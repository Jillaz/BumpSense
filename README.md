# BumpSense

**BumpSense** — это Android-приложение, которое превращает ваш смартфон в инструмент для анализа качества дорог. Приложение записывает GPS-треки и одновременно анализирует вибрации через акселерометр, вычисляя **индекс неровности (BumpIndex)** в реальном времени.

---

## 🎯 Для чего это нужно?

*   🚗 **Оценка качества дорог** в вашем районе.
*   🚴 **Поиск маршрутов с ровным покрытием** для велосипеда.
*   📝 **Документирование проблемных участков** для жалоб в ЖКХ.
*   📊 **Анализ стиля вождения** и состояния подвески автомобиля.
*   📈 **Сбор статистики по неровностям** на длинных маршрутах.

---

## ✨ Возможности

### 📍 Запись треков

*   ✅ Автоматическая запись GPS-маршрута в реальном времени.
*   ✅ Работа в фоновом режиме (Foreground Service).
*   ✅ Автоматическое сохранение каждые 50 точек.
*   ✅ Защита от потери данных при краше.

### 🎨 Визуализация

*   ✅ Интерактивная карта на базе MapLibre (OpenStreetMap).
*   ✅ Цветовая индикация неровностей:
    *   🟢 **Зелёный** — ровная дорога (bumpIndex 0-33)
    *   🟡 **Жёлтый** — небольшие неровности (34-66)
    *   🔴 **Красный** — значительные неровности (67-100)
*   ✅ Отображение текущей позиции (синяя точка).
*   ✅ Просмотр истории поездок.

### 📊 Анализ данных

*   ✅ Вычисление индекса неровности (BumpIndex) в диапазоне 0-100.
*   ✅ Частота опроса акселерометра: **15 Hz**.
*   ✅ Скользящее окно для сглаживания данных.
*   ✅ Обновление индекса неровности для соседних точек в радиусе **10 м**.

### ⚙️ Настройки

*   ✅ Регулировка частоты GPS (1-10 секунд).
*   ✅ Настройка порога чувствительности акселерометра.
*   ✅ Автоматическое сохранение треков по таймеру (5-60 минут).
*   ✅ Минимальное смещение для новой точки (0-10 метров).
*   ✅ Тёмная и светлая темы.

### 💾 Управление данными

*   ✅ Экспорт всех треков в **GeoJSON**.
*   ✅ Импорт треков из файла.
*   ✅ Добавление треков без очистки базы.
*   ✅ Редактирование и удаление отдельных треков.
*   ✅ Фильтрация треков по области видимости карты.

### 🔋 Оптимизация

*   ✅ Динамическое переключение режимов GPS (`HIGH_ACCURACY` / `BALANCED_POWER`).
*   ✅ Batch insert в базу данных (снижение нагрузки в **100 раз**).
*   ✅ Упрощение геометрии треков (алгоритм Ramer-Douglas-Peucker).
*   ✅ Дебаунс обновлений карты (500 мс).
*   ✅ WakeLock для удержания CPU во время записи.
